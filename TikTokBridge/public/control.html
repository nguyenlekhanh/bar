Quick start

📖 User Guide

Four steps to go live on TikTok with a 3D dance floor.

Step 1

🖥️ Launch ÔNG CHÚ MMO Live

Open OngChuMMO_Live.exe. Wait until NODE ONLINE appears in the corner of the game window.

Step 2

📱 Connect TikFinity

Open TikFinity Desktop → sign in → start the LIVE. Go to the 🔴 Live tab → enter the username → Connect LIVE.

Step 3

📺 Add to OBS

Add a Game Capture source → select the ÔNG CHÚ MMO Live window. Press F2 in game to enable Chroma Key.

Step 4

🎮 Test it

Go to 🧪 Test Lab → press 30 viewers. Use 🎯 Events to test gifts by hand.
